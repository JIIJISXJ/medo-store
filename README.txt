# MEDO Winter Store

متجر ملابس شتوية بسيط وجاهز للتشغيل.

## التشغيل
افتح ملف `index.html` في أي متصفح.

## أهم التعديلات
1. في `script.js` عدّل المنتجات والأسعار.
2. غيّر رقم واتساب الموجود في `index.html` و`script.js`:
   201000000000
   إلى رقمك بصيغة دولية بدون + أو مسافات.
3. لاستبدال صور الإيموجي بصور حقيقية، ضع صور المنتجات داخل مجلد `images` وعدّل `product-img` في `script.js`.

## رفع الموقع مجاناً
يمكن رفع هذه الملفات على خدمات استضافة مواقع ثابتة مجانية مثل GitHub Pages أو Netlify أو Cloudflare Pages.

ملاحظة: `medo.com` دومين مستقل؛ هذا المشروع لا يحجز الدومين تلقائياً.
